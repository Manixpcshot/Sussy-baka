# 🎮 Sussy Baka - Web Board Game

یک بازی تخته تعاملی وب‌محور ساخته شده با HTML، CSS و JavaScript خالص.

## 🚀 ویژگی‌ها

- بازی دوز (Tic Tac Toe) کاملاً تعاملی
- طراحی مدرن و ریسپانسیو
- بدون نیاز به فریمورک یا کتابخانه خارجی
- قابل اجرا مستقیماً در مرورگر

## 📦 نحوه استفاده

1. فایل `index.html` را باز کنید
2. بازی را شروع کنید!

## 🎯 نحوه بازی

- دو بازیکن به نوبت حرکت می‌کنند (X و O)
- اولین نفری که 3 علامت پشت سر هم (افقی، عمودی یا مورب) بگیرد برنده است
- دکمه Reset برای شروع بازی جدید
