# 🎮 دوز حرفه‌ای - Sussy Baka

یک بازی **دوز (Tic Tac Toe)** کامل، حرفه‌ای و مدرن با قابلیت‌های پیشرفته!

## ✨ ویژگی‌های کلیدی

### 🎯 حالت‌های بازی
- **🤖 بازی با هوش مصنوعی** - چالش با ربات هوشمند در 4 سطح سختی
- **👥 بازی دو نفره محلی** - بازی با دوستان روی یک دستگاه

### 🤖 هوش مصنوعی قدرتمند
- الگوریتم **Minimax** با بهینه‌سازی کامل
- 4 سطح سختی:
  - 😊 **آسان** - برای مبتدی‌ها
  - 🤔 **متوسط** - چالش معمولی
  - 😎 **سخت** - برای حرفه‌ای‌ها
  - 😈 **غیرممکن** - شکست‌ناپذیر!

### 🏆 سیستم پیشرفته امتیازدهی
- سیستم **XP و Level** کامل
- امتیاز بر اساس نتیجه بازی
- پاداش ویژه برای شکست دادن AI در سطوح سخت‌تر
- محاسبه نرخ برد

### 📊 آمار و تاریخچه
- ثبت تمام بازی‌ها
- نمایش آمار کامل (برد، باخت، مساوی)
- تاریخچه 50 بازی آخر
- نرخ برد با نمودار گرافیکی

### 🎨 رابط کاربری زیبا
- طراحی **مدرن و حرفه‌ای**
- 4 تم رنگی متفاوت (آبی، سبز، نارنجی، تیره)
- **انیمیشن‌های روان** و چشم‌نواز
- پشتیبانی کامل از **RTL** و زبان فارسی
- **طراحی ریسپانسیو** کامل (موبایل، تبلت، دسکتاپ)
- ذرات پویای پس‌زمینه

### 🔊 صدا و جلوه‌های ویژه
- افکت‌های صوتی برای تمام اکشن‌ها
- کنترل حجم صدا
- قابلیت خاموش/روشن کردن صدا

### ⚙️ قابلیت‌های اضافی
- 💡 **راهنمایی هوشمند** - نمایش بهترین حرکت
- ↩️ **برگشت حرکت** - لغو حرکت‌های قبلی
- ⏱️ **تایمر بازی** - ثبت مدت زمان بازی
- 💾 **ذخیره خودکار** - ذخیره پیشرفت در LocalStorage
- 🎬 **صفحه لودینگ** زیبا

## 🚀 نصب و اجرا

### روش 1: اجرای مستقیم

فقط کافیه فایل `index.html` رو باز کنی و بازی آماده است! 🎉

```bash
# کلون کردن پروژه
git clone https://github.com/Manixpcshot/Sussy-baka.git

# ورود به پوشه
cd Sussy-baka

# باز کردن در مرورگر
open index.html
```

### روش 2: استفاده از Live Server

```bash
# نصب Live Server (اگر نصب نکردی)
npm install -g live-server

# اجرای سرور
live-server
```

### روش 3: استفاده از Python

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

سپس به `http://localhost:8000` برو.

## 🎮 نحوه بازی

### شروع بازی

1. **بازی با AI**: روی دکمه "بازی با هوش مصنوعی" کلیک کن، سطح سختی را انتخاب کن
2. **بازی دو نفره**: روی دکمه "بازی دو نفره" کلیک کن

### کنترل‌ها

- **کلیک روی خانه**: انجام حرکت
- **🔄 شروع مجدد**: شروع بازی جدید
- **💡 راهنمایی**: نمایش بهترین حرکت
- **↩️ برگشت**: لغو آخرین حرکت
- **🏠 منوی اصلی**: بازگشت به منو

### سیستم امتیازدهی

- **برد**: 50 XP + پاداش سختی
  - آسان: +10 XP
  - متوسط: +25 XP  
  - سخت: +50 XP
  - غیرممکن: +100 XP
- **مساوی**: 20 XP
- **باخت**: 5 XP
